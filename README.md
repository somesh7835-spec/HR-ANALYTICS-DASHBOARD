# HR-ANALYTICS-DASHBOARD

## 📊 Project Overview
This project is an interactive HR Analytics Dashboard created using Power BI and Excel data.

The dashboard helps analyze:
- Employee Attrition
- Salary Distribution
- Department-wise Performance
- Gender Analysis
- Job Satisfaction
- Employee Count

---

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
- DAX
- Data Cleaning

---

## 📁 Files Included
